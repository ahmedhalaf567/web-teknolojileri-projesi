# Kişisel Web Sitesi Projesi

## Proje Hakkında
Bu proje Sakarya Üniversitesi Web Teknolojileri dersi kapsamında hazırlanmıştır.

Projede HTML, CSS, JavaScript ve Bootstrap kullanılarak kişisel bir web sitesi geliştirilmiştir.

## İçerik
- Ana Sayfa
- Hakkımda
- Özgeçmiş
- Şehrim
- Mirasımız
- İlgi Alanlarım
- İletişim
- Login Sayfası

## Kullanılan Teknolojiler
- HTML5
- CSS3
- JavaScript
- Bootstrap

## Özellikler
- Responsive tasarım
- Çoklu sayfa yapısı
- Form doğrulama
- API veri çekme
- Mobil uyumlu arayüz
